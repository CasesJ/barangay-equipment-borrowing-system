# Equipment UI Review

## Purpose
This skill helps review and improve the user interface of equipment.html.

## Instructions
1. Locate equipment.html in the project.
2. Examine the existing HTML, CSS, and JavaScript.
3. Check the equipment table layout and readability.
4. Review buttons, forms, labels, and spacing.
5. Identify responsive design problems.
6. Recommend improvements based on the actual code.
7. Preserve existing functions and backend connections.
8. Explain recommendations before modifying any code.
9. Do not modify files without user approval.

## Expected Output
- UI issues identified
- Recommended improvements
- Files reviewed
- Suggested testing steps

## Safety Rules
- Do not delete existing equipment features.
- Do not modify unrelated files.
- Do not claim tests passed unless they were performed.
